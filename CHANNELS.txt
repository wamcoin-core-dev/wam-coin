 THREE COPIES OF THE SOURCE, AND WHY

 The repository is published at GitLab, GitHub and Gitea, at three
 different companies. All three hold the same commits and the same tags
 and are updated together. None of them is the one that matters: the
 chain, the site and the downloads do not pass through any of them, and
 if one disappears the other two are already there.

 That is written here because of what happened on 24 September 2026,
 when this project had one and lost it, and the repository, every
 release download and the whole website went dark in the same minute.
 A reader who finds one of the three gone should not need to be told
 where to go. He should already be holding the other two.

 github.com/wam-coin-official is ours and is locked. Nobody else can take

 THE ONE ACCOUNT THAT PROVES ITSELF WITHOUT US

 Every other line above asks you to trust either this file or the platform
 it names. A "website" field on a profile is text somebody typed, and an
 impostor types the same text.

 The Bluesky handle is different. It is not a name we chose on Bluesky --
 it is this domain:

   @wamcoin.org

 Bluesky grants a domain as a handle only to whoever can write a DNS record
 under it, and it re-checks. So the handle is a statement by the domain
 itself, and you can read that statement without us and without Bluesky:

   dig +short TXT _atproto.wamcoin.org

   "did=did:plc:exxxhvsr3nals4cabrviatmt"

 Whoever controls wamcoin.org published that record, and only whoever
 controls wamcoin.org could. Nobody can forge it without taking the domain,
 and if somebody takes the domain, this file is gone too.

 That is the strongest identity proof this project has anywhere, and it is
 stronger than the signature on this file for one narrow purpose: it needs
 no key of ours to check, only a DNS query anybody can run.


 WHAT NOBODY OFFICIAL WILL EVER DO
 ---------------------------------

   * ask you for a seed phrase, private key, or wallet file
   * ask you to send coins anywhere to "verify", "unlock" or "register"
   * ask you for money, in any currency, for any reason
   * message you first
   * offer you a guaranteed return, an allocation, or an early price

 Every one of those is the whole of crypto fraud. There is no sixth kind.
 The correct response to all five is to stop reading.


 HOW TO CHECK THIS FILE
 ----------------------

 Accounts that link to each other prove very little: whoever takes one of
 them can point it at a row of impostors. So this file is meant to be
 signed.

   curl -O https://wamcoin.org/CHANNELS.txt
   curl -O https://wamcoin.org/CHANNELS.txt.asc
   gpg --verify CHANNELS.txt.asc CHANNELS.txt

 The fingerprint that must come back is published in SECURITY.md in the
 source repository, and nowhere else. Compare it character by character.
 A signature that verifies against some other key proves nothing at all.

 GnuPG will also print, on a perfectly good signature:

   gpg: WARNING: This key is not certified with a trusted signature!

 That is not a failure and it is not about this file. It means only that
 you have not told your own keyring that you trust our key -- which you
 should not do on first contact anyway. The line that matters is the one
 that says "Good signature", and the fingerprint underneath it. If you see
 "BAD signature", that is the real thing, and it means these bytes are not
 the bytes we signed.

 The key that signs this is kept offline and is not on any machine that
 faces the internet. The same key signs every release from v0.1.6, so the
 signature on your download and the signature on this list are the same
 claim, made once and checkable twice.

 A signature covers exact bytes. This file is revised whenever a channel is
 added, and every revision needs a new signature -- so if the verification
 fails, the likely reason is that you hold the signature of a different
 revision. Fetch both again from the same place, together.

 Revisions 1 and 2 were never signed at all, and said so, but gave a reason
 that had stopped being true: that the key ceremony had not been held. It
 had. The file simply had not been signed with it, and nobody noticed the
 sentence had gone stale for a fortnight.


 WHAT THIS FILE DOES NOT CLAIM
 -----------------------------

 That the software is safe. No third-party security audit has been done.
 That the coin is worth anything. It has no price and may never have one.
 That the project will continue. Most do not.

 This file establishes who is speaking. Nothing more.
